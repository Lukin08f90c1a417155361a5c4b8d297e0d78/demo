## Лабораторная работа №4 (Безопасность)

В проект добавлена аутентификация и авторизация на базе Spring Security.

### Аутентификация
*   Используется HTTP Basic Auth.
*   Пароли хранятся в базе данных в виде BCrypt-хешей.
*   Тестовые пользователи (создаются в `DataInitializer`):
    *   Логин: `admin`, Пароль: `password` (Роль: `ROLE_ADMIN`)
    *   Логин: `user`, Пароль: `password` (Роль: `ROLE_USER`)

### Авторизация (Права доступа)
*   **Все пользователи (Аутентифицированные):** могут просматривать списки предметов и заявлений (GET).
*   **Пользователь (USER):** может создавать заявления о пропаже и претензии на предметы.
*   **Администратор (ADMIN):** может создавать найденные предметы, подтверждать передачу вещей, а также выполнять все действия обычного пользователя.

### CSRF-защита
Для всех изменяющих запросов (POST, PATCH, DELETE) требуется наличие CSRF-токена.
*   Токен можно получить, выполнив GET-запрос на `/api/auth/csrf`.
*   В ответе придет JSON с токеном, который необходимо передавать в заголовке `X-XSRF-TOKEN` при последующих запросах.
